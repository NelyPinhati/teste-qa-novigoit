# Teste Técnico - QA Pleno/Sênior - Seguradora VidaMais

Bem-vindo(a) ao repositório do teste técnico para a vaga de QA na Novigo IT, em parceria com a seguradora **VidaMais**.

## 🌍 Cenário de Negócio
A seguradora VidaMais está desenvolvendo um novo portal de **cotação de seguros de automóveis**.

### Funcionalidade em foco: **Cotador de Seguro**
O usuário deve poder:
- Informar **placa** e **CPF**
- Escolher o **tipo de cobertura** (Simples, Completa, Premium)
- Informar se deseja cobertura para terceiros (Sim ou Não)
- Clicar em "**Gerar Cotação**"
- Receber o valor estimado da apólice

---

## ✅ Tarefas obrigatórias

### 1. Planejamento de Testes Funcionais
- Elaborar **5 casos de teste** funcionais
- Criar **3 cenários negativos**

### 2. Reporte de Defeitos
- Simular **2 bugs** com:
  - Título, descrição, passos para reproduzir, resultado esperado e real, severidade e prioridade

### 3. Testes Não-Funcionais
- Listar e explicar **3 tipos** (performance, segurança, etc.)

### 4. Validação de API *(hipotética)*
- Descrever como validaria uma API da funcionalidade "Gerar Cotação"

### 5. Automacao *(esperado para Sênior, desejável para Pleno)*
- Automatizar **1 caso de teste** (usando a ferramenta de sua preferência)
- Explicar a escolha da ferramenta e estrutura

### 6. Risco e Priorizacao
- Explicar como você priorizaria os testes usando critérios de risco

---

## 📤 Entrega via Pull Request
1. Fork este repositório
2. Crie uma branch com seu nome (ex: `qa-nome-sobrenome`)
3. Adicione seus arquivos, pastas, scripts e documentação
4. Crie um **Pull Request** até a data combinada

> Pode entregar os testes em formato `.pdf`, `.docx`, `.md` e os scripts em repositórios organizados por pastas.

---

## ⚠️ Proibição de uso de IA
O uso de ferramentas como **ChatGPT, Copilot ou similares** está **terminantemente proibido** neste teste.

Queremos avaliar **sua capacidade própria de análise, escrita e lógica de testes**. O uso de IA será identificado e resultará na desclassificação imediata.
